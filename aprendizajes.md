# Mis aprendizajes 🎓

## Resumen del curso

A lo largo de este curso aprendí principalmente las bases de GitHub: cómo crear repositorios de manera local y subirlos a la nube. También aprendí cómo funciona la inteligencia artificial por medio de presentaciones, cómo se conforma la tecnología, a descifrar números encriptados, operaciones lógicas y Windows PowerShell. La verdad, me gustó bastante este curso a pesar de ciertas notas 😊

## Temas principales

1. Git y GitHub
   1. Crear repositorios de manera local
   2. Subirlos a la nube de GitHub
2. Tecnología e inteligencia artificial
   1. Cómo funciona la inteligencia artificial
   2. Cómo se conforma la tecnología
3. Lógica y herramientas
   1. Descifrar números encriptados
   2. Operaciones lógicas y Windows PowerShell

## Comandos aprendidos 🚀

| Comando | Función | Ejemplo |
|---------|---------|---------|
| git add | Prepara archivos | git add archivo.py |
| git commit | Guarda cambios | git commit -m "msg" |
| git push | Sube a GitHub | git push origin main |
| git pull | Baja cambios | git pull origin main |
